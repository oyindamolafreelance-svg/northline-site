Document translation

Documents translated, and formatted to match.

We translate documents and format the result so it still looks like the original. For UK use we certify the translation ourselves. Where another country requires a sworn translator, we arrange one through a vetted partner.

Why it helps

  • Clear handling of stamps, tables and scans
  • Certified wording only where it is accurate
  • Desktop publishing when the layout matters, including Asian scripts

What is included

  • Document translation
  • Certified translation for UK use
  • Birth and marriage certificates
  • Driving licences
  • Academic transcripts
  • Business statements and reports
  • Technical manuals
  • Multilingual desktop publishing
  • Translation, editing and proofreading

How it works

  1. File

    Upload a clear scan or the original file on the quote form. For very sensitive files, ask us for a private transfer link.

  2. Use

    Tell us who will read it and whether a certified or sworn translation is required.

  3. Work

    Translate, edit, then a final check.

  4. Delivery

    You receive the file type we agreed.

Who it is for

People and firms who need certificates, statements or manuals in another language.

Questions

Are you sworn translators?

No. The UK has no sworn translators. We certify translations for UK use. If an authority abroad requires a sworn translator, we work with a vetted partner and say so in the quote.

Which file formats do you accept?

Word, Excel, PowerPoint, PDF, InDesign, and photos or scans. Ask about any other format.

Do you translate into English?

Yes. Most document work is into English, from any of the languages we cover.
