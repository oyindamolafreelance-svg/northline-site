website localization services

The same product, in their language.

We localise websites, software interfaces and store listings. The glossary is locked. A person reviews what ships. Live interpreting is not offered.

Why it helps

  • Layout checked when the text grows
  • Search terms researched in the target language
  • A quote from a URL or a file

What is included

  • Website translation
  • App and software localisation
  • Store listing localisation
  • Transcreation for lines that cannot be translated straight
  • Glossary for the product

Process

  1. Files

    Send a URL, a string file or a page export.

  2. Terms

    We agree names, tone and what must not change.

  3. Translate

    A translator works in context, then an editor reviews.

  4. Fit

    We check length, links and locale URLs.

Who it is for

Software companies, ecommerce brands and agencies shipping a product into a new market.

Questions

Do you only translate the words?

No. We also check buttons, metadata and how the language is structured on the site.

Can you quote from a URL?

Yes. A URL or a file is enough to start.
