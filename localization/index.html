Website and app localisation

The same product, in their language.

We localise websites, software interfaces and store listings. The glossary is agreed first, and a person reviews everything that ships.

Why it helps

  • Layout checked when the text gets longer
  • Search terms researched in the target language
  • A quote from a URL or a file

What is included

  • Website translation
  • App and software localisation
  • Store listing localisation
  • Transcreation for lines that cannot be translated directly
  • A glossary for your product
  • Right-to-left layout checks for Arabic and Persian
  • Translation of new content as you publish it

More than the words

Localisation also covers dates, currencies, number formats, address forms, payment methods and legal pages. German buyers, for example, expect an Impressum page. See a page change language to watch what changes.

How it works

  1. Files

    Send a URL, a string file or a page export.

  2. Terms

    We agree names, tone and what must not change.

  3. Translate

    A translator works in context, then an editor reviews.

  4. Fit

    We check length, links and locale URLs.

Who it is for

Software companies, online shops and agencies taking a product into a new market.

Questions

Do you only translate the words?

No. We also check buttons, metadata and how each language is structured on the site.

Can you quote from a URL?

Yes. A URL or a file is enough to start.

Which CMS do you work with?

WordPress with WPML or Polylang, Shopify Markets, Webflow Localization, and plain HTML or string files. Ask about others.

What happens when we add pages later?

New content can be translated as you publish it, as part of a care plan or on request.
