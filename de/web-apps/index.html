Web-Apps

Web-Apps für den Zweck gebaut, nicht aus der Vorlage.

Wir entwickeln individuelle Webanwendungen und Progressive Web Apps und verbinden sie mit den Tools, die Sie bereits nutzen.

Ihr Vorteil

  • Ein Produkt, das Ihr Team betreiben kann
  • Integrationen vor der Entwicklung festgelegt
  • Der Code gehört Ihnen

Leistungsumfang

  • Individuelle Webanwendungen
  • Progressive Web Apps
  • API- und Drittanbieter-Integrationen
  • Design der wichtigsten Ansichten
  • Oberflächen, die für Übersetzung vorbereitet sind

Ablauf

  1. Umfang

    Wir halten fest, was die erste Version können muss und was nicht.

  2. Ansichten

    Sie geben die wichtigsten Abläufe frei, bevor programmiert wird.

  3. Entwicklung

    Wir liefern in Etappen, die Sie durchklicken können.

  4. Übergabe

    Repository, Zugänge und eine kurze Anleitung. Betreuung ist optional.

Für wen

Softwarefirmen, Agenturen und Betriebe, denen eine Tabelle oder ein Plugin nicht mehr reicht.

Fragen

Wem gehört der Code?

Ihnen, sobald die vereinbarten Honorare bezahlt sind.

Lässt sich eine Web-App auf dem Handy installieren?

Eine Progressive Web App ja. Eine Store-App ist eine eigene Leistung, siehe Mobile Apps.
