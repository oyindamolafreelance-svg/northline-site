Wartungspläne

Wartungspläne, damit die Website weiter funktioniert.

Eine Website braucht Updates, Backups und jemanden, der prüft, ob sie erreichbar ist. Die Betreuung ist ein monatlicher Plan. Hosting, Domain und Analytics können Sie auch einzeln buchen.

Ihr Vorteil

  • Updates nach Plan
  • Eine feste Ansprechperson, wenn etwas ausfällt
  • Domain und Code bleiben Ihr Eigentum

Leistungsumfang

  • Website-Wartung
  • Sicherheitsupdates
  • Backups
  • Verfügbarkeitsprüfung
  • Verwaltung von Hosting und Domain
  • Einrichtung von Analytics
  • Kleine Textänderungen
  • Übersetzung neuer Seiten bei mehrsprachigen Websites

Ablauf

  1. Zugang

    Wir listen auf, was wir brauchen. Die Konten bleiben auf Ihren Namen.

  2. Ausgangslage

    Wir dokumentieren Ladezeit, Formulare und Backups.

  3. Routine

    Updates folgen dem gewählten Plan.

  4. Bericht

    Sie erhalten monatlich eine kurze Notiz, was sich geändert hat.

Für wen

Inhaber, die nicht selbst merken wollen, dass das Kontaktformular nicht mehr funktioniert.

Fragen

Verwalten Sie unsere Domain?

Nein. Domain und Code bleiben auf Ihren Namen.

Können wir kündigen?

Ja. Die Kündigungsfrist steht in Ihrem Plan, und Sie behalten alles.

Betreuen Sie auch Websites, die Sie nicht gebaut haben?

Ja, nach einer kurzen Prüfung von Aufbau und Hosting.

Beschreiben Sie Ihr Projekt. Sie erhalten ein schriftliches Angebot, bevor die Arbeit beginnt.
