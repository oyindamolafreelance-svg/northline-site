Proofreading and revision

A second linguist checks the translation you already have.

You have a translation from a freelancer, a colleague or a machine, and you need to know it is right. We check it and return tracked changes with a short summary.

Why it helps

  • You know exactly what changed and why
  • Errors are classed by type, not waved through
  • The level of check is agreed before we start

What is included

  • Proofreading: the translation is read alone for spelling, grammar, punctuation and style
  • Revision: the translation is compared with the source for meaning, omissions and terminology
  • Editing of machine translation output
  • Checks of websites and apps in the browser or on a test build
  • Tracked changes in Word, comments in a PDF, or edits in a bilingual file such as XLIFF

How it works

  1. Send

    The translation, the source text and any glossary.

  2. Level

    We agree proofreading or full revision.

  3. Check

    A linguist works through the text and marks every change.

  4. Report

    You get the corrected file and a short summary of the issues found.

Who it is for

Businesses, agencies, students and authors who already have a translation and want it checked.

Questions

What is the difference between proofreading and revision?

Proofreading reads the translation on its own. Revision compares it line by line with the source, so it also catches mistranslations and missing text.

How is it priced?

Per 1,000 words or per hour. Send both files and you get a fixed price.

What if the translation is too poor to fix?

We tell you, and quote a new translation instead.
