Our own site

This website is the digital sample.

We sell speed, search and build quality, so this site is built the way we build for clients. Here are the facts you can check yourself.

What is in it

  • Plain HTML and CSS. Scripts only run the menu, the animations and the 3D scenes
  • 3D scenes built with three.js and served from this site. They load after the page is ready and switch off when your device asks for reduced motion or to save data
  • Two font files, served from this site, not from Google
  • No cookies, no analytics and no third-party trackers
  • Every page in English and German, linked with hreflang
  • Labelled form fields, keyboard navigation and a skip link
  • Hosted on GitHub Pages, with HTTPS
