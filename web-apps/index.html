Web apps

Web apps built for the job, not a template.

We build custom web applications and progressive web apps, and we connect them to the tools you already use.

Why it helps

  • A product your team can run
  • Integrations agreed before the build
  • The code belongs to you

What is included

  • Custom web applications
  • Progressive web apps
  • API and third-party integrations
  • Design of the main screens
  • Interfaces ready for translation

How it works

  1. Scope

    We write down what the first version must do, and what it will not do.

  2. Screens

    You approve the main flows before engineering starts.

  3. Build

    We ship in stages you can click through.

  4. Handover

    Repository, access and a short guide. Care is optional.

Who it is for

Software companies, agencies and operators who have outgrown a spreadsheet or a plugin.

Questions

Who owns the code?

You do, once the agreed fees are paid.

Can a web app be installed on a phone?

A progressive web app can. A store app is a separate service, see mobile apps.
