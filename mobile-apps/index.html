Mobile apps

Mobile apps for iOS and Android.

We design and build mobile apps, then we can translate the interface and the store listing. One team, from the first screen to the language your market reads.

Why it helps

  • Screens designed for thumbs, not for a desktop slide
  • Store listing text can be translated with the app
  • You see a test build before it is submitted

What is included

  • iOS apps
  • Android apps
  • Interface design
  • Store listing copy
  • App and store listing translation

How it works

  1. Scope

    We name the first release and the screens it needs.

  2. Design

    You review the flows on a phone-sized layout.

  3. Build

    You install a test build.

  4. Release

    We prepare the submission. Store review times are set by Apple and Google.

Who it is for

Product teams and studios that need a phone app, not a stretched website.

Questions

Do you publish under our account?

Yes. The store accounts stay in your name.

Can you translate the app?

Yes. Strings, screenshots and store text, see localisation.
